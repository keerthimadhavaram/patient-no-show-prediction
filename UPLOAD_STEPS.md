# Upload Steps

## Repository Name

Create a public GitHub repository named:

```text
patient-no-show-prediction
```

## Description

Use this description:

```text
Machine learning project predicting patient no-shows using Python, Pandas, Scikit-learn, feature engineering, and model evaluation.
```

## Upload

1. Unzip this package.
2. Open the `patient-no-show-prediction-final` folder.
3. On GitHub, click `Add file` → `Upload files`.
4. Drag all files and folders from inside this folder.
5. Commit message:

```text
Initial commit - Patient No-Show Prediction
```

6. Click `Commit changes`.
